Tips
- Full-page captures work best: the cards show the top of the page and crop the rest.
- Keep each file under ~1600px wide, saved as WebP (quality 75–80). The page resizes them on the GPU anyway; smaller files just load faster on phones.
- The same file is used for both the browser-window cards and the phone cards.
